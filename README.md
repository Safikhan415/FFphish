FFphish

FFphish is an educational phishing simulation tool designed to help organizations and individuals test and improve their awareness of phishing attacks in a controlled, ethical environment.

⚠️ Ethical Purpose & Legal Disclaimer

FFphish is strictly for legitimate security purposes only.

· Use only on systems you own or have explicit written permission to test.
· Never use this tool for malicious activities, harassment, or illegal purposes.
· Users are solely responsible for ensuring their compliance with local laws and regulations.
· This tool is intended for:
  · Security awareness training
  · Authorized penetration testing
  · Educational cybersecurity exercises
  · Improving organizational security posture

Misuse of this tool may result in legal consequences.

Features

· Educational phishing simulation scenarios
· Security awareness training templates
· Campaign tracking and reporting
· Customizable phishing templates (for authorized testing only)
